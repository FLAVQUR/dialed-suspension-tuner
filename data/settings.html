Bike Profiles

What a profile includes

A profile is a bike's name, wheel/travel info and suspension setup. The active one is kept up to date by itself: every change made below is saved into it, and renaming the bike renames it. Save As… starts a new profile from the current setup and switches to it, leaving the one you were on as it was. Switching bikes loads that profile's values below.

Sensor calibration (the Sensors tab) is not part of a profile — it stays as-is, since it's tied to how the sensors happen to be mounted right now, not to which bike is active.

Suspension Setup

About these fields

Only some forks/shocks split compression and rebound into low/high-speed adjusters. Leave a dial blank if your fork/shock doesn't have it (e.g. a fixed-shim HSC with no click count) — the tuning suggestions only mention dials you've actually got. 0 is a real setting, not "none": use it when the dial exists and sits at zero clicks. With the − / + buttons, − from 0 clears the field back to "no dial" and + from blank starts it at 0.

The model, click counts, tokens and pressure aren't used in any calculation, just kept for reference and shown alongside each run — the model also names the part in the run's "Copy for AI" prompt. Include the revision (B1, C1…): it changes how many tokens fit and the click ranges. Static Sag (captured in the Sensors tab) is the exception: Run Analysis uses it to judge whether a ride's average travel looks too firm or too soft for how the bike was set up.

Suspension Calibration

How to calibrate

Zero and Max teach the sensor where each end of the travel is: Zero with the suspension fully extended, Max with it fully compressed — measured with a ruler against the Front Wheel Travel / Shock Stroke set in the Bike tab. Max keeps refining itself if you ever bottom out harder during a ride, so it never needs recapturing for that.

Sag is how far the bike settles under your weight, sitting still. One capture reads both ends at once, since your weight loads them together.

Stand the bike truly vertical and keep it still for about 2 seconds. Redo it whenever the master unit is re-mounted or moved to another bike.

How zeroing works

The master sits tilted inside the frame, so its raw roll/pitch aren't the bike's lean and pitch. Zeroing records which way is "up" in the sensor's own axes so the run page can rotate the data into the bike's frame.

Use a wall or a stand, checked with a level if you can: whatever lean the bike has at that moment becomes 0°, so a bike held 5° off leaves every run 5° off.

It is stored on the device with the suspension calibration, not in a bike profile; each run keeps a copy of the reference it was recorded with, so older runs are never re-interpreted.

Home Network

What happens if it can't connect

The device tries this network first and falls back to its own Access Point automatically if it can't connect within 20 seconds. Use the Connection Mode selector above to switch immediately instead of waiting.

Forgot a Password?

Hold the record button for 10 seconds while the device is idle (not recording) to reset the Access Point and home network settings back to factory defaults. The LED blinks magenta to confirm, then the device restarts.

Recording

Saves power and avoids interference during a run. Turn off to keep the dashboard reachable so you can stop a run remotely.

What this changes

How many rows a run records each second. The suspension is read fresh for every row; GPS and IMU repeat their last reading between their own updates (the IMU reports 100 times a second). A higher rate captures more suspension detail and grows the run file in proportion.

500 Hz is the rate the device has been tested at. 1000 Hz is in beta: it has not been through a real ride yet, and it asks the SD card to take twice the data. If a run recorded at 1000 Hz shows "Rows dropped" in the Runs list, the card could not keep up — go back to 500.

Analysis

How many of your most recent runs the Trends page loads and analyzes. Each one is a full CSV read, so a higher number means a slower page — 5 to 100.
